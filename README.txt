黏菌觀察室 Slime Mold Atlas — 完整網站下載版

使用方式
1. 請先完整解壓縮 ZIP，不要直接在壓縮檔內開啟網頁。
2. 使用電腦的 Chrome、Edge、Firefox 或 Safari 開啟 index.html。
3. 首頁及五個子頁、圖片、圖解與動畫皆已包含，可離線瀏覽。
4. 影片、Google 表單及外部參考資料需連網。若本機開啟時播放器受到限制，請點選影片下方「在原平台觀看」。
5. 中英切換可直接使用；瀏覽器在本機檔案模式下，可能不會跨頁保留語言偏好。

修改與使用
HTML、CSS、JavaScript 原始碼皆包含在內，可用文字編輯器或 Visual Studio Code 修改。
請保持資料夾結構不變。需要自行架站時，可將本資料夾內容上傳至支援靜態網站的主機。
本下載版使用相對路徑，支援解壓縮後直接開啟。
